§01

About

Saya Rayhan Ferdisnyah Mardani, bergelar A.Md.Kom setelah menyelesaikan pendidikan Diploma Tiga di bidang Manajemen Informatika. Saya senang mengubah kebutuhan yang masih berupa ide menjadi antarmuka dan sistem yang benar-benar bisa dipakai orang lain.

Fokus saya ada pada pengembangan web, mulai dari menyusun struktur halaman, menghubungkannya ke basis data, sampai memastikan tampilannya rapi di berbagai ukuran layar. Saya terbiasa bekerja step-by-step: memahami masalah dulu, baru menulis kode.

  • Terbiasa bekerja dengan HTML, CSS, dan JavaScript sebagai fondasi front-end.
  • Memahami alur logika pemrograman dan struktur basis data relasional.
  • Terus belajar praktik pengembangan web modern dan version control.

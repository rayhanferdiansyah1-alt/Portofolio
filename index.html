§01 / PROFILE

About me

Membangun sistem bukan hanya tentang kode, tetapi tentang memahami masalah, menyusun data, dan menghasilkan solusi yang berguna.

“Ide yang jelas harus bisa diterjemahkan menjadi sistem yang jelas.”

Saya Rayhan Ferdisnyah Mardani, bergelar A.Md.Kom setelah menyelesaikan pendidikan Diploma Tiga di bidang Manajemen Informatika. Saya tertarik pada pengembangan aplikasi web dan sistem informasi yang membantu proses kerja menjadi lebih terstruktur.

Fokus saya berada pada pengembangan web dari sisi antarmuka, logika aplikasi, hingga basis data. Saya menggunakan Laravel dan PHP untuk backend, MySQL untuk pengelolaan data, serta HTML, CSS, dan JavaScript untuk membangun tampilan web.

  • Membangun aplikasi CRUD dan sistem informasi berbasis web.
  • Menggunakan Laravel, PHP, MySQL, HTML, CSS, dan JavaScript.
  • Memahami relasi database, autentikasi, role, dan alur data aplikasi.
  • Memperhatikan struktur UI agar sistem mudah digunakan.
  • Terus mengembangkan kemampuan melalui project dan praktik langsung.

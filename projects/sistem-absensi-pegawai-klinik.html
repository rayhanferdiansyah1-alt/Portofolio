01 / OVERVIEW

PROJECT OVERVIEW

Satu alur data untuk kebutuhan kehadiran pegawai.

Proses kehadiran pegawai tidak hanya berhenti pada pencatatan jam masuk dan jam keluar. Data tersebut juga berhubungan dengan cuti, jadwal shift, lembur, rekap kehadiran, dan informasi penggajian.

Sistem ini dirancang agar data kehadiran dapat dikelola dalam satu aplikasi dan digunakan kembali untuk kebutuhan administrasi tanpa melakukan pencatatan berulang.

02 / PROBLEM

THE CHALLENGE

Menghubungkan absensi, shift, dan administrasi pegawai.

  • 01

    Status kehadiran harian

    Admin membutuhkan informasi yang jelas mengenai pegawai yang sudah atau belum melakukan absensi.

  • 02

    Perhitungan lintas shift

    Sistem harus menangani jadwal kerja siang dan malam, termasuk jam kerja yang melewati pergantian hari.

  • 03

    Data yang saling terhubung

    Absensi, cuti, lembur, dan penggajian harus menggunakan sumber data yang konsisten.

03 / SOLUTION

THE SOLUTION

Sistem berbasis peran dengan data kehadiran terpusat.

Aplikasi memisahkan hak akses admin dan pegawai. Pegawai dapat melakukan absensi serta mengajukan kebutuhan administrasi, sedangkan admin mengelola data pegawai dan memantau aktivitas kehadiran.

Setiap proses menggunakan data yang terhubung melalui database sehingga rekap kehadiran dan informasi penggajian dapat disusun secara konsisten.

04 / FEATURES

CORE FEATURES

Fitur utama yang membentuk sistem.

01

Role-based access

Pemisahan halaman dan kewenangan untuk admin dan pegawai.

02

Check-in & check-out

Pencatatan waktu kehadiran pegawai berdasarkan tanggal kerja.

03

Pengajuan cuti

Pengajuan cuti pegawai dengan status persetujuan dari admin.

04

Shift & lembur

Pengelolaan jadwal shift serta perhitungan durasi kerja tambahan.

05

Rekap kehadiran

Ringkasan kehadiran berdasarkan periode dan data pegawai.

06

Informasi penggajian

Penyusunan informasi gaji dan slip berdasarkan data yang tersedia.

05 / PROCESS

DEVELOPMENT PROCESS

Dari kebutuhan bisnis menuju alur aplikasi.

  1. 01

    Requirement analysis

    Mengidentifikasi aktor, kebutuhan absensi, aturan shift, cuti, lembur, dan penggajian.

  2. 02

    System design

    Menyusun alur proses, struktur database, relasi data, dan pembagian hak akses.

  3. 03

    Implementation

    Mengembangkan modul menggunakan Laravel, PHP, Blade, dan MySQL.

  4. 04

    Functional testing

    Menguji validasi form, status absensi, hak akses, dan hubungan antarmodul.
